## Собственный проект

Тема проекта: каталог игр

Главный класс: Game

Почему этот объект нужен программе:
Game описывает одну игру в каталоге: её название, жанр, год выхода и рейтинг.
Без такого класса пришлось бы заводить по 4 отдельные переменные на каждую игру,
а с классом все данные одной игры хранятся вместе, и игр можно создавать сколько угодно.

Какие данные хранит объект:

- Title (название игры, string)
- Genre (жанр, string)
- ReleaseYear (год выхода, int)
- Rating (рейтинг от 0 до 10, double)

Какие значения задаются через конструктор:
Title, Genre, ReleaseYear — эти данные у каждой игры свои и известны при создании.

Какие значения можно задавать автоматически:
Rating — у новой игры в каталоге рейтинга ещё нет, поэтому конструктор ставит Rating = 0.
Какое значение я решил задавать автоматически и почему?
Rating = 0. У только что добавленной в каталог игры ещё нет оценок,
поэтому логично, что её рейтинг начинается с нуля. Передавать 0 при каждом
создании объекта было бы лишним — конструктор ставит его сам.

### Добавленное действие для класса Game

Действие: добавление часов игры.
Параметр: количество часов.
Проверка отказа: если передать 0 или отрицательное число, ранний return отменяет действие (было 0, добавили 15 - стало 15, попытались добавить -5 - осталось 15).
